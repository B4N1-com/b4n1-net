# b4n1-net

Sovereign transport: sealed UDP frames with HMAC, AEAD and acknowledgements.

One native core, thin SDK wrappers for 7 languages (Python, Node.js, Ruby, PHP, Java, .NET, Go).

## Install

```bash
pip install b4n1-net          # Python
npm install b4n1-net          # Node.js
gem install b4n1net           # Ruby
dotnet add package B4n1Net     # .NET
composer require b4n1/b4n1-net  # PHP (Packagist)
go get github.com/B4N1-com/b4n1-net/sdks/go  # Go
```
